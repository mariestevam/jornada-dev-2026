🚀 Jornada Dev 2026 - Landing Page Interativa

Uma Landing Page moderna, responsiva e interativa desenvolvida para um evento fictício de tecnologia e inteligência artificial. O projeto foi construído como parte do meu portfólio de Desenvolvimento Front-End para demonstrar conceitos práticos de estilização, manipulação do DOM e experiência do usuário (UX/UI).

✨ Funcionalidades Principais

🌓 Modo Escuro / Claro (Dark Mode): Alternância fluida de temas com persistência da preferência no localStorage.

⏱️ Cronômetro Regressivo: Contador em tempo real calculando os dias, horas, minutos e segundos até a data do evento.

📝 Formulário de Inscrição Interativo: Validação de dados do usuário com emissão instantânea de um passaporte VIP/ingresso digital através de um modal customizado.

📱 Design Totalmente Responsivo: Layout adaptável para smartphones, tablets e desktops utilizando Tailwind CSS.

🎨 UI/UX Moderna: Efeitos visuais de gradiente, cards interativos, tipografia limpa com a fonte Inter e ícones com FontAwesome.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica e acessível.

Tailwind CSS: Estilização ágil através de classes utilitárias e gerenciamento do tema escuro.

JavaScript: Lógica do cronômetro, manipuladores de eventos do DOM e persistência no navegador.

FontAwesome: Ícones vetoriais modernos.

Google Fonts: Tipografia da família Inter.

📂 Como Executar o Projeto Localmente

Clone o repositório:

git clone https://github.com/seu-usuario/jornada-dev-2026.git


Acesse a pasta do projeto:

cd jornada-dev-2026


Abra o projeto:

Dê um duplo clique no arquivo index.html para abrir diretamente no seu navegador.

Ou utilize a extensão Live Server no VS Code para rodar com Live Reload.
